# 周易今日运势

一个纯娱乐性质的每日运势生成器：模拟传统"三枚铜钱法"起卦，得到本卦（以及可能的变卦），再结合卦象的上下卦五行属性，生成事业、财运、感情、健康四个维度的趣味解读，并渲染成好看的可视化卡片。

**重要边界**：这是文化娱乐内容，不是命理指导或人生决策依据。呈现给用户时语气应该轻松、好玩，必要时可以提醒"仅供娱乐参考"。

## 使用流程（只准走这一条）

**不要手抄 `data.js`，不要自己 `str.replace` 占位符，不要从零写 HTML。**  
`data.js` 很长，读不全就会截断；给 `__TODAY__` 再包一层引号会变成 `const TODAY = ""2026-08-22"";` 语法错误。

在会话工作区根目录跑技能自带脚本，一次生成自包含 HTML：

```bash
python3 <skill-base>/scripts/build_fortune.py --cheer N --salt "witch-N" -o 今日运势.html
```

没有 cheer / salt 时：

```bash
python3 <skill-base>/scripts/build_fortune.py -o 今日运势.html
```

脚本会：
1. 调用 `divine.py` 算出这一卦（含 cheer 的吉凶词、`blessing`、四宫格）
2. 把 `assets/data.js` **整文件**内联进 `__DATA_JS__`
3. 把 `__TODAY__` 换成 `YYYY-MM-DD`（模板里已有引号，**不要再加引号**）
4. 把 `divine.py` 的 JSON 注入 `PRESET`，页面加载后**直接渲染这一卦**，并播模板自带动画
5. 把成品写到 `-o` 指定的路径

首页小巫女任务里会带 `cheer=N` 和 `salt=witch-N`，原样传给上面的命令。cheer 0–6，越大越吉；禁止「大凶」「倒霉」。

可选参数：`--date YYYY-MM-DD`（默认今天）、`--salt`、`--cheer`。

「再摇一卦」仍走模板里的 JS 起卦（可换问题），默认首屏必须是脚本算出的 PRESET。

### 不要自己渲染卡片

视觉、铜钱动画、爻线、印章、四宫格都在 `assets/fortune_template.html` 里。`build_fortune.py` 已经套好。用户要换风格时，可以在生成后再微调 CSS，但**不要改 `<script>` 里的起卦哈希 / 爻位 / 卦表查询**。

下面是模板里已经实现的结构（了解即可，不必重做）：

1. **头部**：日期 + 标题"今日运势 · 周易一卦"，营造一点东方玄学氛围（可用深色背景 + 金色/朱红点缀、水墨风或星空底纹，避免庸俗的紫色渐变卡通风）。
2. **起卦动画**：六个"铜钱"从上到下依次落下/翻转的小动画（CSS transition/animation 即可，不必很复杂），对应 `lines` 里从初爻到上爻的六次投掷，每枚铜钱定住后显示对应的阴爻(- -)或阳爻(—)，动爻额外加一个小圆点或高亮描边提示"动爻"。
3. **本卦展示**：大号显示 `original_hexagram.symbol`（Unicode 卦象字符，字号可以很大，作为视觉主角）+ 卦名 + 吉凶等级词（用颜色区分：大吉/吉=暖色调，平=中性色，宜谨慎=冷色调，不要用"凶"这种吓人的词，脚本里也没有输出"凶"）+ 一句 `gist` 大意。
4. **变卦展示**（仅当 `changed_hexagram` 不为 null 时显示）：可以做成"点击/翻转查看变卦"的小交互，说明"今日卦象有动爻，事情可能会有变化，变卦为 XX"。
5. **四宫格运势**：事业/财运/感情/健康四个卡片，各配一个简单图标（emoji 即可，比如 💼 💰 💗 🌿），文字用 `fortune` 里对应内容。
6. **底部信息条**：幸运色（用对应颜色的小色块展示）、幸运数字、今日建议 `advice`。若 JSON 有 `blessing`，放在建议上方，语气轻松。
7. **免责声明**：小字注明"本内容基于传统周易起卦法则生成，仅供娱乐参考，请勿作为重大决策依据"。

### 设计要点

- 单文件 HTML，CSS/JS 内联，不依赖外部字体或图片资源（可以用系统字体 + emoji）。
- 配色建议走"暗色国风"路线：深墨绿/深靛蓝/黑色背景，搭配朱红、赤金作为强调色；卡片用半透明毛玻璃效果（backdrop-filter）会很有质感。
- 阴爻阳爻不要只用纯文字"1/0"，要画出真正的爻线（阳爻是一条实线，阴爻是中间断开的两段线），这是整个视觉的核心元素，必须做对。
- 铜钱投掷动画不需要物理引擎，一个简单的 CSS `@keyframes` 旋转+落下，配合延迟（每枚铜钱依次落定，从初爻到上爻）就有很好的效果。
- 移动端也要能看：卡片宽度用相对单位，四宫格在窄屏下可以变成两列或单列。
- 交互加分项：点击卦象符号可以有个小提示/tooltip 说明"本卦"是什么意思；如果做成可以重新摇一卦的按钮，需要注意——重新摇卦应该视为"换个日期/换个问题"，不要破坏"今日运势"这个概念的确定性，可以做成"再问一件事"输入框，传入不同 `--salt` 效果。

如果用户有特别的风格要求，只许在 `build_fortune.py` 产出的 HTML 上改外观，不要重做占位符替换。

### 参考数据文件（一般不需要直接读取，脚本已经处理好了）

- `references/hexagrams_64.json`：64 卦卦名、大意、吉凶等级
- `references/trigram_grid.json`：八卦上下卦对照速查表，用于由六爻反查卦序号

如果需要在 UI 文案里进一步展开某一卦的含义，可以读这两个文件补充细节，但**卦名、卦序、五行归属必须以脚本计算结果为准**，不要自己现编。
