# 新闻事实

只调用 `fetch_facts`，参数只有 `ts_code`。维度和 `days=3` 已绑定，不要改地址，不要调用 Tushare。

返回 JSON：

- `rows[]`：时间、标题、来源、方向、范围、类别、量级、依据、当日反应、是否反映、说明。
- `facts[]`：同一批事件编号；`text` 已拼好时间与消化信息。结论用到的 id 放进 `fact_ids`。
- `facts` 为空：写「近 3 日窗口内没有取到」，stance=中性、strength=弱；不要编，不要写成「公司从来没新闻」。

读法摘要（细则见 prompt.md）：
- 去重：同一事件一次冲击；时效看最早报道，可信度看最硬来源。
- 消化：只用事实里的价格/反映字段；缺了就写无法判断，不编涨跌。
- 热搜：抖音/百度热搜优先当情绪展示，不要整段当噪声；掘金/V2EX 等缺字段才噪声。热搜单独不打强方向。
- 证据不足：缺时间、来源、摘要对不上 → 降权或中性弱，不补全（大众热搜标题本身可作情绪依据）。
- 时效：≤48h 原方向；48h～3 日可计但默认弱；3～7 日放轻；7～30 日背景；＞30 日不计方向。
- suggested_questions 有条件生成，没事可返回 []。
- text 里不要出现英文双引号 `"`，标题引语改成「」。
- 开场不要再 load 其他技能。拿到事实后立刻输出开场 JSON 结束。
