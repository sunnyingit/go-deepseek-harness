# 网络搜索（search-web）

问题不在个股基本面/资金/新闻射程内时（宏观政策、行业事件、人物、常识），
用 `fetch_web_search` 搜公开网络，拿标题+摘要+日期的前几条作事实参考。

## 口径

- 来源是公开网页摘要，**不是**行情/财报数据；数字要谨慎转述，注明「网络搜索，截至 X 日」。
- 摘要可能滞后或互相矛盾：给结论时优先取多条一致的部分，冲突就摆出两种说法。
- 搜不到（results 为空）就直说「网上没搜到」，禁止编造。
