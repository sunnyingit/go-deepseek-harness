# Report & Meeting Minutes Writer

Covers three related but distinct internal-communication documents. Identify which one is being asked for before writing — they have different structures and different audiences.

| 文档 | 场景 | 读者 | 核心问题 |
|---|---|---|---|
| 日报 (Daily) | 每天/每次站会同步 | 团队内部 | 今天做了什么，明天做什么，卡在哪 |
| 周报 (Weekly) | 每周向上/向团队同步 | 主管、跨部门协作方 | 这周的关键结果是什么，风险是什么 |
| 会议纪要 (Minutes) | 会议结束后归档 | 与会者 + 未到场但需要知情的人 | 讨论了什么、定了什么、谁去做 |

判断依据：如果对方给的是"今天/这周做了什么"的流水账，走日报/周报流程；如果给的是会议记录、转写文本、或者一堆分散的讨论笔记，走会议纪要流程。拿不准就直接问一句。

## 写作总原则

- **结论先行，不按时间顺序叙事**。读者是来找"结果"和"要我做什么"的，不是来看过程的。
- **能用数字就不用形容词**："完成 3/5 个任务，覆盖率提升到 82%"，不是"进展顺利"。没有数字的时候，宁可写"待评估"，也不要编一个听起来精确的假数字。
- **结构做区分，不用大段文字**：已完成 / 进行中 / 问题与求助 / 计划，各自独立成块，一行一条，不要写成段落。
- **行动项必须有负责人和截止时间**，缺一个都要标出来问清楚，不要自己编一个"尽快""近期"这种模糊表述去填坑。
- 中文语境下默认用中文输出，语气克制、就事论事，不做无实质内容的场面话（"大家辛苦了""再接再厉"这类可以省略，除非对方明确要）。

## 日报 / 周报怎么写

1. **收集素材**：如果对方直接给了要点，照着整理；如果连的工具里有任务系统/日历/commit 记录，优先从那里取事实，而不是让对方口述。素材不全的时候，明确列出"需要你补充"的条目，不要脑补。
2. **固定结构**：
   ```
   ## 今日/本周完成
   - [量化的结果]

   ## 进行中
   - [事项] — 预计 [时间] 完成

   ## 问题 / 需要协调
   - [卡点] — 需要谁配合 / 需要什么支持

   ## 明日/下周计划
   - [下一步要做什么]
   ```
3. **周报额外加一行"本周一句话总结"放在最上面**——这是主管唯一会认真看的一行，其余内容是备查用的。
4. 周报如果和日报内容重叠，用"详见 X 月 X 日日报"指一下，不要原样复制粘贴凑字数。
5. 篇幅：日报控制在能一屏看完，周报可以稍长，但每个 bullet 仍然一行说清楚，不写复合句。

## 会议纪要怎么写

1. **先提取会议元信息**：会议主题、时间、参会人。参会人如果从记录里推不全，标注"参会人待补充"而不是瞎猜漏掉谁。
2. **按议题分段，不按发言人分段**。一个议题一段：先一句话概括讨论了什么共识/分歧，再单独一行写"结论/决定"——讨论过程和最终结论要能一眼区分开。
3. **所有行动项汇总成一张表放在文末**，不要散落在各个议题段落里让人漏看：

   | 事项 | 负责人 | 截止时间 | 状态 |
   |---|---|---|---|
   | | | | 待启动 |

   负责人或截止时间在原始记录里没有明确给出的，不要替对方指派或编日期，标"待确认"并提示对方补上。
4. **只记录说了什么、定了什么，不加整理者自己的评价或建议**——纪要是客观记录，不是会议纪要作者的读后感。
5. **不要逐字转写**。哪怕拿到的是完整的会议转写文本，也要概括提炼，不能把大段原话照抄进纪要（这也是版权和可读性的双重要求——没人会去读一份和转写稿一样长的"纪要"）。除非某句话的原始措辞本身就是决议内容（比如需要精确记录某个承诺的原话），一般情况一律改写成客观陈述句。

## 输出格式

- 默认输出 Markdown 正文，方便直接粘进飞书文档/企业微信/Confluence 这类内部工具，不主动生成 Word 文件。
- 如果对方需要 Word/PDF 归档，或者已经有固定的公司模板，改用 docx/pdf 技能，并且严格照着模板的格式走，不要用本技能里的默认结构覆盖对方已有的模板。
- 如果不确定对方所在团队有没有固定格式，问一次就够了，得到答案后记住，不要每次都重新问。

## 常见问题

- **把会议纪要写成完整转写稿**——最常见的失败模式之一，必须概括提炼，见上文第 5 点。
- **行动项没有负责人/截止时间**——纪要产出后如果没人知道自己该做什么、什么时候做完，这份纪要就没有达到目的，宁可留白标注"待确认"也不要编。
- **日报/周报写成叙事段落**——读者是来扫一眼的，不是来读故事的，坚持结构化的短 bullet。
- **周报和日报内容重复黏贴**——参考上文第 4 点，用指引代替复制。
