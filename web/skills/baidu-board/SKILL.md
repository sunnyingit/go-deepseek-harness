# 百度财经榜

调用 `fetch_baidu_board`。参数：

- `board`：榜单，默认 `finance`（财经榜）。可选 `realtime`（实时热搜）、`civil`（民生榜）。用户没点名就用财经榜。
- `limit`：取前几条，默认 15，最多 50。

工具请求股票服务 `GET /api/v1/shared/baidu-board`，不要改地址。

返回：

- `board_name`、`updated_at`：榜单名和百度更新这张榜的时间。
- `stale`：为 true 说明百度这次没取到，给的是 `fetched_at` 那次的旧榜；回答里要说明「这是 xx 时间取到的榜」。
- `facts[]`：`id` 形如 `bd.1`，`text` 里有名次、标题、热度、新/热标。
- `rows[]`：名次、标题、热度、标签、简介，回答按这些字段写。

回答只依据这次返回的 `rows`/`facts`：

- 榜单是「大家在搜什么」，不是利好利空。不要因为上榜就说某只股票或板块会涨。
- 标题和热度只抄返回的内容，不补充榜外的报道，不编热度数字。
- 用户要把热点对应到某只股票或板块时，先说榜上哪几条相关；没有相关的就说榜上没有，再建议用 `fetch_news` 搜这个主题。
- 不给买卖建议、目标价或概率。
