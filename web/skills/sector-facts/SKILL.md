# 板块事实

只调用 `fetch_facts`，参数只有 `ts_code`。维度已绑定，不要改地址，不要调用 Tushare。

返回一个 JSON：

- `facts[]`：`id` 以 `sp.` 开头。`text` 已写成百分数或阶段名。结论引用 `text`，不要拿 `value` 再乘 100。
- 是否属于、成分角色、阶段只引用这些事实。申万行业和同花顺概念分开写。没有明确阶段就说没有明确阶段。
- 阶段是这一轮行情的位置，不是导入期、成长期、成熟期、衰退期。没有市占率、竞争对手、政策方向，就不要编。
- 不要自己补充同行业公司。概念名称里没有上游、中游、下游、设备、材料这些词时，不要自封产业链位置。
- 角色是领涨、中军、跟风这些价格角色，不是龙头或腰部。市值排名只抄 `text`。
- 开场只写 100 字以内的一段结论：主板块、阶段、是核心还是跟风、命中的预警。不要表格。追问也不必用表格。数字只抄 `text`。
- `review_state` 为 computing 时，事实还在整理，不要写成没有取到或返回为空。
