01 给谁用 +

面向每天要产出内容、算数、交表格的岗位，而不是实验室里的研究员。

运营

日报周报、活动页、常规内容，交给 Agent 起草与排版，把时间留给判断。

HR

招聘周报、绩效汇总、通知页面，固定格式反复做，最适合交给 Agent。

财务

表格对账、口径统一、月度简报，让 Agent 按既有规范跑完初稿。

销售运营

线索看板、战报、客户材料，一键按模板生成，随数据更新。

02 三件能力 +

围绕「做完可复用」而非「聊一次」设计的核心能力。

技能市场

日报 / 周报、视觉 HTML、表格、品牌四条线，按岗位挑现成技能直接编排，不用从零写提示词。

会话可回放

每一步过程和产出都有留痕，历史文件不丢，随时回到任意一步重跑或复查。

灰度发布 · 一键回滚

新编排先在小范围放量，出问题一键回退到上一个稳定版本。

Token 用量可见

个人空间直接看自己的 Token 消耗，成本透明，心里有数。

03 本季节奏 +

三个节点，按顺序推进，每一步都有明确的条件。

10 月 · 编排协议封口

统一技能编排的协议与规范，此后技能接入有稳定契约。

评测集补齐 → 扩到 20%

等评测集充分覆盖常见场景后，灰度比例提升到 20%。

04 客户怎么开始 +

一句话：先去技能市场挑一个最像你日常作业的技能，让它先跑一单。

第一步 · 挑技能

在技能市场里找到日报、表格或 HTML 页面这类最贴近日常的起点。

第二步 · 跑一单

给它一份真实数据或模板，看它产出，再根据自己的口径改两轮。

第三步 · 固定成技能

满意后存成可复用的编排，之后每周打开就能跑，不用重新交代。
